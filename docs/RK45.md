# RK45 and boundary localization

Both methods integrate `dr/ds = ±B/|B|` on a trilinearly interpolated native
XYZ field. Dormand–Prince RK45 advances the order-five estimate, controls its
embedded order-four discrepancy and reuses the final derivative (FSAL).
A full trial adds six evaluations after the first k1; rejected trials reuse k1.
RK2 is midpoint integration with a quadratic continuous extension for events.

## Adaptive controls

All budgets are per branch. ds and max_steps are required.

| Option | Omitted value | Meaning |
| --- | --- | --- |
| rtol | 1e-6 | relative to fixed physical error_scale |
| atol | 1e-9 times minimum cell width | absolute coordinate error scale |
| error_scale | per-axis minimum cell widths, including seam | scalar or three physical lengths |
| max_step | local minimum cell width | resolution safeguard; explicit infinity opts out |
| max_step_cells | omitted: 1 local cell | optional positive local-width multiplier; mutually exclusive with explicit max_step |
| min_step | 32 eps64 times minimum cell width | lower trial bound |
| max_length | infinity | integrated arc limit |
| max_attempts | 10*max_steps+100 | accepted plus rejected trials; integer <=2**53 |
| boundary_tol | 1e-9 times minimum cell width | small terminal/retry resolution |

The RMS error norm uses `atol + rtol*error_scale[i]`, independent of absolute
coordinate origin and accumulated periodic travel. The controller uses
`0.9*error**(-1/5)` clipped to [0.2,5], with no immediate growth after rejection.
The local grid cap can dominate the cost: loosening rtol does not reduce steps
when the cell limit already determines them. Tight rtol, curvature, nonsmooth
interpolation, trial failures or boundary events can still shorten steps below
that cap. Choose tolerance and mesh resolution together. The default physical
error scales use global per-axis minimum widths; on strongly stretched grids,
an explicitly chosen error_scale may be useful and needs convergence checks.

The local grid cap prevents common one-cell features being skipped by large
error-free trials; it is not a guarantee of subcell feature resolution.
A global explicit max_step overrides it. Study step limits with mesh resolution.

Coordinates, work state, errors and arc accumulation use float64, even when
field/output dtype is float32. Tolerances cannot control original field
quantization or the rounding of saved coordinates. Endpoint metadata remains
float64. Translating to extremely large origins can still lose representable
coordinate increments despite origin-independent error scaling.

## Events

Nonperiodic face detection uses the quartic Dormand–Prince extension: extrema
partition each coordinate polynomial into monotone intervals, then roots
identify the first outward crossing, including exits followed by re-entry
inside one step. A conservative outward-rounded range filter bypasses root
isolation only when strict containment is proven. The existing polynomial
regressions cover roundoff/cancellation and all axes/branches.

A valid event trial is evaluated at its first root and projected exactly onto
the selected face. An out-of-domain RK stage is never interpolated outside
the mesh: the trial is shortened using its tangent face estimate or halved.
Weak *trial* fields are retried at shorter steps; an initial weak field stops.
Nonfinite fields stop rather than cross invalid data. Retries are bounded by
min_step, max_attempts and boundary_tol. A tangent estimate alone cannot
establish a physical crossing; only roundoff-close terminal correction uses
linear projection. x/y/z precedence resolves numerically tied face events.
RK2 similarly takes a partial final step to the face through its quadratic
extension, rather than discarding the last ds.

The event is a root of a numerical trajectory. Exact mathematical tangencies
and shallow crossings remain sensitive to accumulated integration error.
boundary_tol is not a global trajectory or event-time error guarantee.
A pure polynomial contact without an outward crossing does not terminate,
but trajectory error can turn a true tangency into a tiny crossing.

When a roundoff-close RK45 endpoint reaches or slightly overshoots a face
with outward velocity, the event search can retry using the dense polynomial
relative to that face. This uses the scale of the normal displacement to
resolve a crossing and project its endpoint. A trial with an exterior endpoint
and no resolved event is shortened.

## Output and limits

Arc lengths are sums of accepted full/partial step lengths in float64.
max_length termination takes precedence when that limit is attained.
Rejected attempts do not advance position or arc. nfev includes attempted
field evaluations, including failed stages, for one branch integration.
See [API](API.md) for storage passes, counters and exit codes.

Dense extension is used internally for face events; there is no independent
public dense-output/output_spacing API. Integration tolerance, saved geometry,
scalar sampling and angular resampling all need convergence checks.
Trilinear fields are only C0 across cells: a fifth-order integrator does not
make the interpolated simulation field fifth-order accurate. Higher-order
field interpolation remains a separately validated development task.


## Allocation and warm-up

The hot RHS returns three scalar components and a code; RK stages and event
workspaces are allocated once per branch, not per field evaluation. Boundary
root isolation uses reusable small workspaces. The fast interior range test
uses a conservative forward-error margin rather than repeated nextafter calls;
uncertain cases still run the complete extrema/root search. Tests check range
certificates against exact Decimal coefficient enclosures and independent roots.
No fastmath assumptions are introduced.

Kernels specialize by component dtype and C/F/strided layout. For steady-state
benchmarks, first call the tracer with representative arrays/controls and at
least one representative seed, discard that result, then measure later calls.
This warms the relevant signature, not all possible layouts. Disk cache hits
are different from fresh compilation. See [validation](../validation/README.md).

### Rounded face intervals

RHS roundoff clamping and final face recognition use the same inclusive
coordinate interval, face-noise <= q <= face+noise. Comparing abs(q-face)
to noise instead can disagree at the interval edge because subtraction of
the bounds rounds differently. This formerly let one accepted near-face point
escape terminal projection and subsequently underflow. The noise multiplier
remains 32*float64 epsilon; arc correction still obeys boundary_tol, nonnegative
used arc and max_length.


### Initial tangency and limit ties

For a seed exactly on a face, a zero normal component or one within the local
interpolation cancellation bound allows a one-sided curvature check. The bound
uses the absolute weighted normal samples and their storage precision. A
determinate outward curvature terminates at zero arc. For inward curvature the
first stage uses a tangent direction. The branches can use different one-sided
cells at a knot or periodic seam. A resolved normal component keeps its sign.

For a face and max_length separated by <=8*eps64*max_length in arc, the length
limit wins. See [the API guide](API.md) for exit codes.
